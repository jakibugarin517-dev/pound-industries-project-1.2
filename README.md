# Pound Industries Personal Website
https://jakibugarin517-dev.github.io/pound-industries-project-1.2/

This is my Project 1 personal interest website about Pound Industries and digital VR assets.

## Pages
- index.html - Home
- products.html - Products
- about.html - About
- contact.html - Contact

## Unique HTML elements
- nav - I used nav for the website navigation.
- aside - I used aside for extra store information.
- article - I used article for the individual product cards.

## Unique HTML attributes
- ping - I used ping on a store link to demonstrate the attribute.
- referrerpolicy - I used it on a store link to control referrer information.
- rel - I used it on store links to describe the link relationship.

The images are local files in the images folder, using the exact names from my asset ZIP.
